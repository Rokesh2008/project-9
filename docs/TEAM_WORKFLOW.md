# Team Workflow

1. Start from `develop`.
2. Pull latest changes.
3. Create a feature branch.
4. Work on the assigned task.
5. Commit and push.
6. Open a PR into `develop`.
7. Review, test and merge.

Branch naming:
- `feature/member1-<task>`
- `feature/member2-<task>`
- `feature/member3-<task>`

Coordinate whenever two people need the same file.
